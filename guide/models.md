# 模型

面板的「模型」卡片列出当前 DSH 支持的模型，选中即用，之后的任务立即生效。

## 内置目录

| ID | 名称 | 说明 |
| --- | --- | --- |
| `deepseek-flash` | DeepSeek-V4.1-Flash | 默认，快且支持图像输入，适合大多数任务 |
| `deepseek-v4-pro` | DeepSeek-V4-Pro | 更强的编码与推理，适合复杂任务，成本更高 |

这份目录来自 DSH `0.2.1-rc.2` 内置的 `DEFAULT_MODELS`，同时作为面板下拉的数据源。

## 账号路由下的在线列表

账号路由启用后，DSH 会在线拉一份 `/models` 列表与内置目录合并，所以
**新模型通常不用改代码就能出现在面板上**。

离线时自动回落到内置目录，不影响使用，只是暂时看不到新增模型。

## 怎么知道当前用的是哪个

面板「任务详情」里每次运行都会记录当次用的模型，和历史记录一起展示。
模型切换对**之后**的任务生效，已经在跑的任务不受影响。

## 切换模型

在面板「模型」卡片点目标模型即可，或调 `panel_set_model` 入口：

```json
{"model": "deepseek-v4-pro"}
```

填未知 ID 会被拒绝并提示可用值，不会静默回退成别的模型。
